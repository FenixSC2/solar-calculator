# Solar Payback Calculator

A plug-in solar savings calculator: pick a setup, enter your electricity rate, and see yearly savings, payback time, and 10/25-year profit.

- Live page: https://fenixsc2.github.io/solar-calculator/
- Compact version for slideshows: https://fenixsc2.github.io/solar-calculator/?embed=1

Everything is in `index.html` (no build step). Formulas follow the calculator at pluginsolarus.com. This is an estimate, not a quote.
